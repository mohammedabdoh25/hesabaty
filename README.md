# حساباتي — تطبيق محاسبي عربي

نسخة MVP قابلة للتوسعة مبنية بلغة Python وKivy، وتخزن البيانات محلياً في SQLite على الجهاز.

## الوظائف الحالية

- لوحة تحكم مختصرة.
- إضافة الأصناف مع الباركود والتصنيف والوحدة والأسعار والمخزون وحد التنبيه وتاريخ الانتهاء.
- فواتير بيع وشراء وتحديث المخزون تلقائياً.
- العملاء والموردون والأرصدة.
- تسجيل المصروفات.
- تقرير إجمالي للمبيعات والمشتريات والمصروفات والربح التقريبي وقيمة المخزون.

## التشغيل على الكمبيوتر

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install kivy
python main.py
```

## بناء APK على Linux

ثبّت Buildozer ومتطلباته ثم نفّذ:

```bash
pip install buildozer cython
buildozer android debug
```

سيظهر الملف داخل `bin/`. ولنسخة إصدار موقعة يلزم إنشاء مفتاح توقيع Android وإعداد بياناته في Buildozer.

## ملاحظات مهمة

هذه نسخة أساس عملية وليست نظاماً محاسبياً قانونياً نهائياً. قبل النشر التجاري أضف صلاحيات المستخدمين، النسخ الاحتياطي/المزامنة، قارئ الباركود، الطباعة، الضرائب حسب بلدك، سجل تدقيق، وإقفال الفترات المحاسبية.
